# SCCS — Suez Canal Cyber Security

First static prototype for the SCCS student hub.

## Files
- `index.html` — page structure/content
- `style.css` — dark cyber UI + responsive design
- `script.js` — mobile menu, theme toggle, search

## Run locally
Open `index.html` in a browser.

## GitHub Pages
Create a GitHub repository, upload these three files to the repository root, then enable:
Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

The generated site can then be opened through the GitHub Pages URL.

## Subject pages
Each subject card now opens a dedicated page under `subjects/` instead of scrolling to a generic section.
